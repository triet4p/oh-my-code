# SPEC 32 — Query registry và DAO

## 1. Định dạng file `.sql`

- UTF-8; BOM `EF BB BF` ở đầu được bỏ.
- CRLF và LF đều được.
- Directive: dòng khớp `^--\s*name:\s*([A-Za-z][A-Za-z0-9_.-]{0,63})\s*$` (không phân biệt hoa thường ở `name`, key giữ nguyên).
- Nội dung giữa directive hiện tại và directive kế tiếp là SQL; `trim()` hai đầu; giữ nguyên dòng bên trong, dấu `;` cuối.
- Dòng directive không nằm trong SQL.
- Bình luận `--` khác trong SQL được giữ nguyên.
- File phải có ít nhất một directive.
- Trước directive đầu tiên: chỉ khoảng trắng hoặc dòng bắt đầu `--`; nếu có ký tự khác → lỗi.
- Không cho directive trùng key.
- Khối rỗng (chỉ khoảng trắng/comment) → lỗi.

Ví dụ `fixtures/notes.sql`:

```sql
-- name: findNoteById
SELECT id, title, body FROM notes WHERE id = ?;

-- name: insertNote
INSERT INTO notes (title, body) VALUES (?, ?);

-- name: listNotes
SELECT id, title FROM notes ORDER BY id;
```

Registry:

```json
{
  "findNoteById": "SELECT id, title, body FROM notes WHERE id = ?;",
  "insertNote": "INSERT INTO notes (title, body) VALUES (?, ?);",
  "listNotes": "SELECT id, title FROM notes ORDER BY id;"
}
```

## 2. API

```java
public final class QueryRegistry {
    public static QueryRegistry load(Path sqlFile) throws IOException, QueryRegistryException;
    public String sqlFor(String type) throws SQLException;
    public Set<String> keys();                 // unmodifiable, insertion order
    public boolean contains(String type);
}
```

```java
public class BasicDao {
    public BasicDao(QueryRegistry registry);
    public void setConnection(Connection connection);
    public PreparedStatement getPrepareStatement(String type) throws SQLException;
    public PreparedStatement getPrepareStatement(String type, int autoGeneratedKeys) throws SQLException;
}
```

`QueryRegistry` không import `java.sql.Connection`, chỉ dùng `SQLException` cho lookup để khớp hợp đồng DAO.

## 3. Lỗi

| Tình huống | Exception | Message |
|---|---|---|
| File không đọc được | `IOException` | mô tả hệ thống |
| Không có directive | `QueryRegistryException` | `No named queries found` |
| Key trùng | `QueryRegistryException` | `Duplicate query name: <key>` |
| Khối rỗng | `QueryRegistryException` | `Query body is empty: <key>` |
| Nội dung trước directive | `QueryRegistryException` | `SQL before first query name` |
| Key sai định dạng | `QueryRegistryException` | `Invalid query name at line <n>` |
| Key không tồn tại | `SQLException` | `Unsupported Query Type` |
| Chưa nạp registry | `SQLException` | `Query registry not loaded` |
| Connection null | `SQLException` | `Connection null!` |
| Generated keys mode sai | `IllegalArgumentException` | `Unsupported auto-generated keys mode` |

Thứ tự kiểm tra ở overload thường: connection → registry → key. Nếu cả connection null và key sai, lỗi connection thắng (khớp nguồn). Riêng overload có `autoGeneratedKeys` kiểm tra mode **trước** connection; mode sai luôn là `IllegalArgumentException`.

## 4. Overload generated keys

Chỉ chấp nhận:

- `Statement.RETURN_GENERATED_KEYS` (1)
- `Statement.NO_GENERATED_KEYS` (2)

Giá trị khác → `IllegalArgumentException` **trước** khi chạm connection. Sau đó gọi `connection.prepareStatement(sql, mode)`.

## 5. Bảo mật cấu hình

- Không có hằng mật khẩu/host/user trong mã, fixture, test.
- Không in SQL/registry ra log ở mức INFO nếu SQL có thể chứa dữ liệu.
- Nếu mở rộng kết nối thật, đọc từ biến môi trường; không log giá trị; không đưa vào `toString`.
- Bài không mở kết nối thật, nên không có credential.

## 6. Ví dụ cụ thể

```java
QueryRegistry reg = QueryRegistry.load(Path.of("fixtures/notes.sql"));
BasicDao dao = new BasicDao(reg);

dao.getPrepareStatement("findNoteById");
// SQLException: Connection null!  (connection chưa set)

dao.setConnection(fakeConnection);
PreparedStatement ps = dao.getPrepareStatement("insertNote");
// fake nhận đúng "INSERT INTO notes (title, body) VALUES (?, ?);"

dao.getPrepareStatement("deleteAll");
// SQLException: Unsupported Query Type

dao.getPrepareStatement("insertNote", Statement.RETURN_GENERATED_KEYS);
// fake.prepareStatement(sql, 1)

dao.getPrepareStatement("insertNote", 99);
// IllegalArgumentException: Unsupported auto-generated keys mode
```

## 7. Trường hợp biên

| # | Tình huống | Kết quả |
|---|---|---|
| 1 | BOM + CRLF | nạp đúng, key không có BOM |
| 2 | Key `findNoteById` | giữ nguyên chữ hoa |
| 3 | Key bắt đầu số | lỗi dòng |
| 4 | Directive lặp | lỗi duplicate |
| 5 | Khối chỉ có `-- comment` | lỗi empty |
| 6 | File chỉ comment | lỗi no named queries |
| 7 | SQL trước directive | lỗi leading SQL |
| 8 | Khoảng trắng trước directive | hợp lệ |
| 9 | `-- NAME: x` | hợp lệ, key `x` |
| 10 | `-- name:x` (không space) | hợp lệ |
| 11 | `-- name: x ` | trim key |
| 12 | `-- name: x y` | lỗi invalid name |
| 13 | SQL chứa dòng `-- name:` thụt lề | **không** phải directive (phải ở cột 0) |
| 14 | SQL chứa `?` | giữ nguyên |
| 15 | Key không tồn tại | `Unsupported Query Type` |
| 16 | Connection null + key sai | `Connection null!` |
| 17 | Registry null | `Query registry not loaded` |
| 18 | Generated keys 1/2 | hợp lệ |
| 19 | Generated keys 0/3/-1 | IllegalArgumentException |
| 20 | `keys()` sửa | `UnsupportedOperationException` |
