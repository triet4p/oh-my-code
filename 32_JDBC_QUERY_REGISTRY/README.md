# 32 — Sổ đăng ký truy vấn JDBC

## Mục tiêu

Tách câu lệnh SQL khỏi mã Java: nạp file `.sql` có các khối được đặt tên thành một registry bất biến, lấy `PreparedStatement` theo loại truy vấn, kiểm tra kết nối và khóa không tồn tại bằng lỗi rõ ràng, hỗ trợ overload lấy generated keys.

## Giá trị

- SQL nằm trong tài nguyên, không rải chuỗi trong DAO; đổi truy vấn không cần sửa logic.
- Học hợp đồng lỗi của DAO: kết nối thiếu khác loại truy vấn không hỗ trợ.
- Học parse định dạng có directive mà không cần thư viện.
- Học bài học bảo mật từ nguồn: **không** nhúng mật khẩu vào mã; cấu hình nhạy cảm đến từ môi trường.

## Ngôn ngữ, độ khó, điều kiện

| Mục | Giá trị |
|---|---|
| Ngôn ngữ | Java 17+ |
| Độ khó | Trung bình |
| Điều kiện | JDK 17, `javac`; không cần MySQL hay JDBC driver |
| Thời lượng gợi ý | 5–6 giờ |

## Nguồn gốc

- Repo: `triet4p/NoteApp`
- File nguồn: <https://github.com/triet4p/NoteApp/blob/main/src/main/java/com/noteapp/dao/BasicDAO.java>
- Hành vi quan sát được:
  - `protected Map<String, String> enableQueries;` và `getEnableQueriesFrom(String sqlFile)` gọi `fileReader.readSQL(sqlFile)`.
  - `getPrepareStatement(String queriesType)`:
    - `if (databaseConnection.getConnection() == null) throw new SQLException("Connection null!");`
    - `if (!enableQueries.containsKey(queriesType)) throw new SQLException("Unsupported Query Type");`
    - `return databaseConnection.getConnection().prepareStatement(enableQueries.get(queriesType));`
  - Overload nhận `autoGeneratedKeys` và gọi `prepareStatement(query, autoGeneratedKeys)`.
  - **Quan sát bảo mật:** file nguồn chứa hằng `DATABASE_PASSWORD = "Asensio1234@"` cùng host/port/user. Bài tập **không** tái tạo mật khẩu hay thông tin kết nối thật; đây là lỗi cần tránh, không phải hành vi để bắt chước.
  - Lớp dùng `SQLDatabaseConnection` và `ISQLReader` làm abstraction; bài giữ tinh thần injection nhưng định nghĩa interface tối giản.

**Phần là thiết kế của bài:** định dạng file `.sql`, validate registry, lỗi khi chưa nạp registry, kiểm tra chế độ generated keys, và test không cần DB.

## Hành vi bài tập yêu cầu

- `QueryRegistry.load(Path)` đọc UTF-8 (bỏ BOM), chấp nhận CRLF, trả map chỉ đọc giữ thứ tự.
- Directive `-- name: <key>` ở đầu dòng; key duy nhất; SQL không rỗng; file phải có ít nhất một khối.
- SQL trước directive đầu tiên chỉ được là khoảng trắng/comment; nếu có nội dung → lỗi.
- `BasicDao.getPrepareStatement(type)`:
  - kết nối `null` → `SQLException("Connection null!")`;
  - registry chưa nạp → `SQLException("Query registry not loaded")`;
  - key thiếu → `SQLException("Unsupported Query Type")`;
  - còn lại trả `connection.prepareStatement(sql)`.
- Overload `autoGeneratedKeys` chỉ nhận `Statement.RETURN_GENERATED_KEYS` hoặc `Statement.NO_GENERATED_KEYS`; khác → `IllegalArgumentException`.
- Không hard-code credential; không log SQL chứa dữ liệu nhạy cảm.
- Registry không phụ thuộc JDBC; có thể test bằng file.
