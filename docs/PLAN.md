# Kế hoạch oh-my-code

## Mục tiêu

Xây dựng lộ trình 60 mini-project tự code, được đúc kết từ mã nguồn các repository của triet4p. Các bài tăng dần độ khó, không giới hạn ngôn ngữ và có thể thực hiện độc lập.

## Mốc

- [x] Sắp xếp 60 bài thành lộ trình, chỉ rõ nguồn và điều kiện tiên quyết.
- [x] Viết README, SPEC và GUIDE cho từng bài.
- [x] Kiểm tra số lượng, nguồn, liên kết và rà soát các hợp đồng tiêu biểu.
