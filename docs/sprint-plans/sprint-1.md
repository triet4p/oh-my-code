# Sprint 1: 60 mini-project tự code

## Mục tiêu và tiêu chí

- Khảo sát từng repository có thể truy cập của triet4p; phân biệt bằng chứng từ code với ý tưởng mở rộng.
- Đề xuất 60 mini-project đặt tên `ID_NAME`, ID duy nhất từ 01 đến 60, thứ tự tương đối từ dễ đến khó.
- Mỗi folder có `README.md`, `SPEC.md`, `GUIDE.md`: mục tiêu và nguồn; hành vi, giới hạn và ví dụ kiểm chứng; hướng dẫn triển khai và gỡ vướng không thay người học code.
- Chỉ rõ dependencies và cách kiểm chứng hợp lý; không tạo code mẫu giả là implementation hoàn chỉnh.
- Kiểm tra số lượng, tên, tính nhất quán và nguồn. Không commit hoặc push.
